# web-version_up
# Web注文システム改修課題

## 1. プロジェクト概要

本リポジトリは、Web注文システムを対象とした改修課題の成果物を管理するリポジトリです。

既存システムのソースコードや設計資料をもとに、現状調査、改修方針の整理、機能追加・変更、テストおよび各種ドキュメントの作成を行っています。

## 2. 改修内容

本プロジェクトでは、段階的なバージョンアップを通じて、以下の機能追加・改善を予定しています。

- **Ver.2：商品カテゴリの拡張**
  - 食品・AV機器・PCカテゴリへの対応
  - カテゴリごとの商品情報および在庫情報の管理
- **Ver.3：顧客・決済機能の拡張**
- **Ver.4：割引機能の追加**
- **Ver.5：SQLインジェクション対策などのセキュリティ改善**

※各バージョンの詳細な対応状況については、該当するフォルダ内の資料を参照してください。

## 3. ディレクトリ構成

| ディレクトリ | 内容 |
|---|---|
| `juchu01/` | 改修前のWeb注文システム |
| `juchu01現状調査/` | 既存システムの現状調査に関する資料 |
| `juchu02/` | Ver.2の改修対象プロジェクト |
| `ver.2/` | Ver.2の設計書・テスト資料・報告書など |
| `sql/` | SQL関連資料 |
| `全体改修方針/` | システム全体の改修方針に関する資料 |
| `提供共有資料/` | 課題で提供・共有された資料 |
| `Servers/` | 開発環境に関する設定ファイルなど |

## 4. 使用技術・開発環境

- Java 11
- Apache Tomcat 9
- JSP / Servlet
- DAOパターン
- H2 Database
- Eclipse

## 5. 資料の参照方法

各バージョンの改修内容、設計、テスト結果については、該当するバージョンのフォルダ内にある資料を参照してください。

Ver.2については、`ver.2/README.md` に記載された案内を起点として、改修概要、設計書、テスト仕様書・結果一覧、改修報告書などを確認できます。

## 6. 補足

本リポジトリは、Web注文システムの改修過程と成果物をバージョンごとに整理・管理することを目的としています。
