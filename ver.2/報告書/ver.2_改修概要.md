# juchu01 ver.2 改修概要

## 1. なぜ改修したか

既存システムは文具・書籍を対象としているため、食品・AV機器・PCを取り扱えなかった。取扱商品を増やし、同じ受注システム上でカテゴリに応じた商品情報・画像・在庫を管理できるようにする必要があった。

## 2. どのような方針で改修したか

- 既存の検索、詳細表示、カート、受注の利用手順と画面配置を維持する。
- 既存のカテゴリ別テーブル、モデル、DAO、詳細JSPの構成を踏襲する。
- `juchu01`と`COSCOMMON01`は変更せず、`juchu02`と`COSCOMMON02`を新たに作成してバージョンを分離する。
- 商品コードの先頭2桁をカテゴリ、先頭4桁をサブカテゴリとして扱う既存方式を拡張する。
- 既存機能への影響を抑え、新カテゴリの固有情報だけを追加する。

## 3. 実施した改修

| 分類 | 実施内容 |
|---|---|
| プロジェクト | `juchu01`をコピーし、改修版を`juchu02`として作成 |
| DB | `COSCOMMON01`を基に`COSCOMMON02`を作成 |
| DB | `FOODS_TABLE`、`AV_TABLE`、`PC_TABLE`を追加 |
| DBデータ | 食品4件、AV4件、PC3件と、各商品の営業所01～03の在庫を登録 |
| Javaモデル | `Foods`、`Av`、`Pc`を追加 |
| Java DAO | `DaoFoods`、`DaoAv`、`DaoPc`を追加 |
| 既存Java | 商品コード03～05のDAO振り分け、詳細画面振り分け、カテゴリコード抽出を改修 |
| JSP | 食品・AV機器・PCの詳細画面を追加 |
| 画像 | 新商品画像をカテゴリ別フォルダーへ配置 |
| SQL | ver.1のSQLをコピーし、ver.2用のDDL・登録・確認SQLを追加 |

## 4. 改修後の動作

- 商品コード先頭2桁でカテゴリ、先頭4桁でサブカテゴリを判定する。
- 食品・AV機器・PCを既存商品と同じ検索、詳細表示、カート追加、受注の流れで扱える。
- 商品詳細では、カテゴリに応じた固有項目を表示する。
- 営業所コード01～03に応じて在庫を取得し、既存の在庫表示・引当処理を利用する。
- `juchu01`の既存ソースとDBは変更せず、`juchu02`・`COSCOMMON02`へ分離して管理する。

## 5. 改修結果

検索、商品詳細、画像表示、カート追加、食品商品の受注、在庫不足、文具・書籍の回帰を確認した。未登録コード指定時の空レスポンスは`juchu01`でも発生するため、ver.2固有の改修不具合ではなく、別課題として報告した。

詳細なDB物理定義は[ver.2_DB物理設計書.md](../設計/DB設計/ver.2_DB物理設計書.md)、クラス、メソッド、画面遷移、処理内容は別紙の[ver.2_改修詳細.md](ver.2_改修詳細.md)に記載する。
